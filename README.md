# OQ YER — Eldor Digital Business Card v2

Версия сделана по архитектуре MIRKO Card:
1. бренд / название
2. статус и имя владельца
3. контакты владельца
4. официальные соцсети
5. Google Maps
6. сохранить контакт

## Файлы

- index.html
- style.css
- script.js

## Данные для замены

Все временные данные находятся в `script.js` в объекте `DATA`:

phone
telegramUsername
oqyerTelegram
lastName

## Фото Eldor

Сейчас используется placeholder, чтобы визитка была готова без фотографии.
Когда будет настоящее фото, можно заменить блок `.photo-placeholder` в `index.html`.
